### 🚀 Selected work

**[Mahindra Manulife Mutual Fund](https://vatsalmotiani.net/work/mahindra-manulife)** · *Next.js · Node.js · SQL · LangGraph*
Modernised a legacy mutual fund platform into one secure, cross-platform system.
- Built **~75% of the backend**, including the distributor portal and the shared payments engine behind **10+ transaction types**
- Unified login that merged legacy folio-level accounts into a single account
- A LangGraph assistant that answers investor questions about schemes and funds

**[Jio Signal](https://vatsalmotiani.net/work/jio-sentiment)** · *TypeScript · Next.js · PostgreSQL · pgvector · LLMs*
A private sentiment intelligence board for the Jio IPO.
- Ingests social and media sources and classifies every mention by **topic, sentiment and entity**
- pgvector semantic search and live rollups that surface shifts in public mood **within minutes**

**[Trade Desk](https://vatsalmotiani.net/work/commodities-automation)** · *Python · FastAPI · LangGraph · PostgreSQL*
Automated shipment assessment and pricing for a global base-metals trader.
- Processing time cut from **3 months to under 5 minutes (98% faster)**
- Runs on shipments averaging **$14M** each, and led to **5 follow-on projects**

**[Spidermania](https://vatsalmotiani.net/work/spidermania)** · *Next.js · MySQL · AWS S3 · CloudFront*
The official fan platform for Marvel's *Spider-Man: Brand New Day*, for Sony Pictures India.
- Community forum, theories and upvotes, plus a short-form video feed
- Near-instant playback through S3 and CloudFront, with moderation tools and engagement analytics
